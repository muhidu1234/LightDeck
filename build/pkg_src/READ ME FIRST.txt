LightDeck 1.21 - one app for all your RGB
==========================================

INSTALL
1. Extract this whole zip (right-click > Extract All). Don't run it from inside the zip.
2. Double-click "Install LightDeck".
   It installs for your Windows user only (no admin needed) and adds Start menu + Desktop shortcuts.
3. Windows may show "Windows protected your PC" because the app isn't code-signed.
   Click "More info" > "Run anyway". (Same for the installer window if it appears.)

FIRST START
- Close other RGB apps first: SignalRGB, iCUE, Armoury Crate, G HUB lighting, Mystic Light,
  RGB Fusion, NZXT CAM... Only one app can control the lights at a time.
- LightDeck starts OpenRGB (included) and Windows asks to allow it as administrator.
  Click Yes so RAM and some motherboards work. If OpenRGB warns about PawnIO, install the free
  PawnIO driver from https://pawnio.eu for RAM / SMBus lighting.
- A welcome window explains the rest (ARGB header LED counts, effects, themes).
- LightDeck opens in the animated Night City window: a menu on the left (Lights, Light settings,
  Preview, Effects, Settings). For LED counts, splitting a cable, Wi-Fi lights and recording a new
  device, use Settings > Classic window (switch back with "Switch to the new look").

WHAT WORKS
- Anything OpenRGB 1.1 supports: most motherboards, ARGB headers, RAM, GPUs, many keyboards,
  mice and LED controllers. List: https://openrgb.org/devices_1.1.html
- Devices without a live lighting mode still follow the effect (slower, or as one color).
- Windows Dynamic Lighting devices (many newer keyboards, mice and headsets) - built in.
  Turn Windows' own Dynamic Lighting off for them (Settings > Personalization > Dynamic Lighting).
- RK N80 keyboard (over its USB cable) - built in.
- Wi-Fi lights: WLED, Philips Hue, Nanoleaf, Govee - Settings > Wi-Fi lights > Search my network.
- Through the maker's own app, while it runs: Logitech G HUB, ASUS Armoury Crate (Aura),
  Corsair iCUE (needs Corsair's free iCUESDK.x64_2019.dll in the drivers folder),
  Razer Synapse (Chroma) and SteelSeries GG.
- Other RGB apps (SignalRGB, Mystic Light, RGB Fusion, NZXT CAM...) fight LightDeck:
  LightDeck warns you, and Settings > Other RGB apps can close them.
- Devices nothing supports are listed in the app under "Found, not controllable".
  "Report a device" there (or in Settings) makes a short list to send so support can be added.

UPDATE / REMOVE
- Update: extract the new version and run "Install LightDeck" again. Your settings are kept.
- Remove: double-click "Uninstall LightDeck".

REQUIREMENTS
Windows 10 or 11, 64-bit. Nothing else - Python and OpenRGB are included.
